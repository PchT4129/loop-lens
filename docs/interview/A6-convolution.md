# 附录 F · 卷积与感受野

> 第一梯队 ①。本项目整个 pipeline 建立在卷积之上，而"感受野"这一节
> 直接解释了为什么 GAP 之后的 512 维可以当作**全局**描述子。

---

## 1. 先问：为什么不用全连接？

一张 224×224 彩色图拍平是 `224×224×3 = 150528` 个数。接到 64 个神经元：

```
全连接 Linear(150528 → 64)  :  9,633,856 个参数
卷积   Conv2d(3→64, k=3)    :      1,792 个参数
                               ↑ 相差 5376 倍
```

**而且这只是一层。**

但参数量还不是最要命的。**最要命的是全连接完全不知道"这是一张图"**——对它来说，`第0个数` 和 `第1个数`（水平相邻像素）的关系，跟 `第0个数` 和 `第50000个数`（图像另一端）的关系**完全等价**。它得从数据里从头学出"哪些像素是邻居"，而这本是**免费的先验**。

---

## 2. 卷积把图像的两个先验硬编码进了结构

### 先验一：局部性（locality）

> 一个像素和周围像素关系密切，和很远的像素基本无关。

识别一条边、一个角、一块纹理，只需要看**局部一小块**。

### 先验二：平移不变性（translation invariance）

> 猫在左上角还是右下角，都是猫。

检测"垂直边缘"这个操作，在图像任何位置都该是**同一个操作**。

> 📌 **卷积不是更聪明，是被喂了正确的假设。** 这才是它参数少却更有效的根本原因。

---

## 3. 卷积在算什么——手算一遍

运算本身**极其简单**：**对应位置相乘，然后全部加起来**（点积）。

```
输入:              kernel:
[1  2  3]          [ 1   0]
[4  5  6]          [ 0  -1]
[7  8  9]
```

kernel 盖在左上角 2×2 区域：

```
盖住: [1  2]      kernel: [ 1   0]
      [4  5]              [ 0  -1]

对应相乘再求和 = 1×1 + 2×0 + 4×0 + 5×(-1) = -4
```

实测输出：

```
[-4  -4]
[-4  -4]
```

左上角确实是 **-4** ✓

kernel 往右滑一格再算：`2×1 + 3×0 + 5×0 + 6×(-1) = -4`。滑完一行往下移，重复。

> 💡 **卷积没有任何神秘之处——就是一个小窗口在图上滑动，每个位置做一次点积。**

（这个 kernel `[[1,0],[0,-1]]` 在做对角方向差分。真实网络的 kernel 是**学出来的**，不是人工设计的。）

---

## 4. 参数共享 ⭐ 最关键的一点

kernel 从左上滑到右下，**用的自始至终是同一组权重**。这叫**参数共享**，带来三个后果：

**① 参数量与图像尺寸完全无关。** 一个 3×3 kernel 就是 9 个数，不管图是 224×224 还是 4096×4096。§1 那个 5376 倍就是这么来的。

**② 平移不变性是"免费"获得的。** 同一个 kernel 在所有位置做同样的事，所以"检测垂直边缘"的能力在任何角落都成立。**不需要用"猫在左上角"和"猫在右下角"两批数据分别教它。**

> 📌 **接上 M2**：卷积本身的平移不变性 + GAP 的平移不变性，共同解释了为什么 `day_right`（横向视角变化）能到 96%。**视角变化在图像上主要表现为平移，而这恰好是 CNN 结构自带的不变性方向。**

**③ 它是一种极强的正则化。** 参数共享等于强行规定"图像各处必须用同一套检测器"，大幅限制模型自由度。用 A3 的话说，这是**架构级正则化**，比 weight decay 那种事后惩罚强得多。

---

## 5. 多通道

**输入多通道**：kernel 也有同样多的通道，各通道分别卷积后**结果相加**成一个数。

**输出多通道**：**有几个输出通道就有几个独立 kernel**，每个产出一张特征图。

```
参数量 = 输出通道 × 输入通道 × kernel高 × kernel宽  (+ 输出通道个 bias)
```

验证 ResNet18：

```
conv1 权重形状: (64, 3, 7, 7) = 64个kernel × 3输入通道 × 7×7
参数量 = 64 × 3 × 7 × 7 = 9408
```

> **读 kernel 形状的口诀：`[输出通道, 输入通道, 高, 宽]`。**

---

## 6. kernel 学到了什么

统计 ResNet18 预训练的第一层 64 个 kernel：

```
偏【颜色/亮度】检测的 kernel: 19 个
偏【边缘/纹理】检测的 kernel: 45 个
权重和接近 0 的比例: 48%
```

**"权重和接近 0" 很说明问题**——权重和为 0 意味着这个 kernel 对"整片均匀区域"输出 0，只对**变化**有反应，也就是在做**差分**、是个变化检测器。

这和几十年来手工设计的滤波器（Sobel、Gabor）**惊人一致**——网络自己学出了人类过去手工设计的东西。

**层级分工：**

| 层 | 学到什么 |
|---|---|
| 第一层 | 边缘、颜色斑块、明暗对比 |
| 中间层（layer2/3） | 纹理、角点、简单几何形状 |
| 高层（layer4） | 物体部件、语义概念 |

> 📌 这解释了 M7 的一条修复建议：**冻结浅层只训 layer3/4**。浅层学的"边缘和纹理"是**任何视觉任务都通用**的，昼夜任务根本不需要改动它们。

## 7. 感受野 ⭐

### 7.1 定义

> **输出特征图上的一个数，是由输入图像上多大一块区域算出来的？** 这块区域就是**感受野**。

第一层 3×3 kernel 的输出只看到原图 3×3。第二层的一个数看的是第一层的 3×3——而第一层每个数又各自看了原图 3×3。**一层层叠加，感受野不断增长。**

### 7.2 递推公式

```
RF_out   = RF_in + (kernel − 1) × jump_in
jump_out = jump_in × stride
```

`jump`（累计步长）是"输出上相邻两点在原图上间隔多少像素"。**每经过一次 stride=2，jump 翻倍**，于是后面每层感受野增长越来越快。

### 7.3 ResNet18 实测（输入 224×224）

```
层              输出尺寸   累计步长    感受野
conv1             112       2         7
maxpool            56       4        11
layer1.0.c1        56       4        19
layer1.1.c2        56       4        43
layer2.0.c1        28       8        51
layer2.1.c2        28       8        99
layer3.0.c1        14      16       115
layer3.1.c2        14      16       211
layer4.0.c1         7      32       243   ← 已超过输入的 224
layer4.1.c2         7      32       435
```

> 📌 **本章最有价值的结论**：
>
> `layer4` 输出的 7×7 特征图上，**每一个点的理论感受野是 435 像素，已超过整张输入图（224）**。
>
> 也就是说 **7×7 上的每个点都"看遍"了整张图**。
>
> **这才是为什么 GAP 之后的 512 维可以当作"全局描述子"** —— 不是因为 GAP 把空间信息平均掉了才叫全局，而是**在 GAP 之前，每个位置就已经是全局的了**。

面试被问"为什么这 512 维能代表整张图"，多数人只会说"因为做了全局平均池化"，你可以说到感受野这一层。

> ⚠️ **补一句严谨的**：435 是**理论**感受野。实际的**有效感受野（effective receptive field）**通常小得多——中心区域贡献远大于边缘，近似高斯衰减。这是 NeurIPS 2016 *Understanding the Effective Receptive Field in Deep CNNs* 的结论。能补这句更好。

## 8. 为什么用两个 3×3 而不是一个 5×5

VGG 的经典洞见，也是现代网络几乎清一色用 3×3 的原因。

两层 3×3 堆叠感受野是 5×5，和单层 5×5 相同。实测参数量：

```
两层 3×3 : 感受野 5×5, 参数 73,856
一层 5×5 : 感受野 5×5, 参数 102,464
```

**感受野相同，参数少 28%。** 而且还有第二个更重要的好处：

> **两层之间夹了一次 ReLU，多了一层非线性。**

单层 5×5 只有一次非线性变换，两层 3×3 有两次。**更多非线性 = 更强表达能力。**

所以"小 kernel 堆深"全面优于"大 kernel 堆浅"——**参数更少、非线性更多、感受野一样**。

## 9. 面试怎么答

### Q1：卷积相比全连接的优势？

> 三点。第一是参数量，224×224×3 的图接 64 个神经元，全连接要 963 万参数，3×3 卷积只要 1792 个，差 5376 倍，而且卷积的参数量与图像尺寸完全无关。第二也是更本质的：卷积把图像的两个先验硬编码进了结构——局部性和平移不变性。全连接对它来说相邻像素和图像另一端的像素是等价的，得从数据里学出"哪些是邻居"，而这本来是免费的先验知识。第三，参数共享本身是很强的架构级正则化。

### Q2：卷积具体在算什么？

> 一个小窗口在图上滑动，每个位置做对应元素相乘再求和，也就是点积。输入多通道时 kernel 也有同样多通道，各通道分别卷积后相加；输出多通道就是有多个独立 kernel，每个产出一张特征图。所以参数量是输出通道 × 输入通道 × kernel 高 × kernel 宽。

### Q3 ⭐：什么是感受野？怎么算？

> 输出特征图上一个数，对应输入图像上多大一块区域。递推公式是 `RF_out = RF_in + (kernel−1) × jump`，其中 jump 是累计步长，每遇到一次 stride 就乘上去。
>
> 我算过 ResNet18：输入 224 时，conv1 之后是 7，layer3 结束是 211，**到 layer4 最后是 435，已经超过输入尺寸了**。这意味着 7×7 特征图上每个点都看遍了整张图——**这才是 GAP 之后的 512 维能当全局描述子的真正原因**，而不只是因为做了平均池化。
>
> 不过要补一句，435 是理论感受野，实际的有效感受野通常小得多，中心贡献远大于边缘，近似高斯衰减。

### Q4：为什么现代网络都用 3×3？

> 两层 3×3 和一层 5×5 感受野相同，但参数少 28%（73856 vs 102464），而且中间多夹了一次 ReLU，非线性更强。这是 VGG 的洞见——小 kernel 堆深全面优于大 kernel 堆浅。
