## 1. QKV 的本质：一次可微的软检索

注意力就是**你项目里做的那件事**——检索。对照看最快：

| 本项目的 VPR 检索 | 注意力 |
|---|---|
| query 特征 | **Q** |
| database 特征 | **K** |
| database 图像本身 | **V** |
| `q @ db.T` 算相似度 | `QKᵀ` |
| `topk` 取前 K 个（**硬选择**） | `softmax` 加权（**软选择**） |
| 返回选中的图 | 返回 `softmax(QKᵀ/√d)·V`（加权平均） |

> 📌 **注意力 = 把"取 top-k"换成"按相似度加权求和"。**
> 动机只有一个：**`topk` 不可导，softmax 可导**。这就是 "soft" 的含义。

**自注意力**：Q、K、V 都来自同一序列——**序列自己检索自己**。

## 2. 为什么除以 √d_k ⭐

### 2.1 实测

```
d_k    | QK^T 标准差  | 注意力熵(满值4.159) |
8      | 3.04        | 2.1190      [不缩放]
       | 1.08        | 3.6585      [除√d]
32     | 5.42        | 0.9388      [不缩放]
       | 0.96        | 3.7265      [除√d]
128    | 11.34       | 0.3642      [不缩放]
       | 1.00        | 3.6842      [除√d]
512    | 22.36       | 0.2161      [不缩放]
       | 0.99        | 3.6810      [除√d]
2048   | 45.95       | 0.0824      [不缩放]  ← 熵几乎归零
       | 1.02        | 3.6718      [除√d]
```

**① 标准差精确按 √d 增长**：实测 `3.04/5.42/11.34/22.36/45.95`，对应 `√d = 2.83/5.66/11.31/22.63/45.25`——**完全吻合**。

**为什么**：`q·k = Σᵢ qᵢkᵢ` 是 d 个独立乘积之和，独立变量求和**方差相加** → 方差 ∝ d → 标准差 ∝ √d。

**② 不缩放时注意力熵从 2.12 崩到 0.08**（满值 4.159）。熵≈0 意味着 softmax **几乎 one-hot**——每个 query 只能看到一个 key。

### 2.2 完整答法

> "`QKᵀ` 是 d 个独立乘积求和，方差正比于 d、标准差正比于 √d。d 越大 logits 越极端，softmax 越接近 one-hot——我实测 d=2048 时注意力熵只有 0.08，满值 4.159，基本塌成了硬选择。
>
> 后果有两个：**信息流被掐断**（每个位置只能看一个位置），以及 **softmax 落在饱和区、梯度对 logits 变化不敏感**。除以 √d_k 把标准差拉回 1 左右，熵稳定在 3.67，**而且与 d 无关**。"

> ⚠️ **一个测量陷阱**：不要用 `softmax(x).sum().backward()` 衡量梯度——**softmax 的和恒为 1，对它求导数学上就是 0**，测出来全是浮点噪声。**熵才是衡量饱和程度的正确指标。**

## 3. 排列等变 → 位置编码的必要性 ⭐

实测：

```
输入顺序打乱 perm = [3, 1, 4, 0, 2]
attn(x) 然后重排  与  重排后再 attn(x)  是否相同: True
```

> **自注意力是排列等变（permutation equivariant）的：打乱输入顺序，输出只跟着打乱，内容一模一样。**

**自注意力根本"看不到"顺序**——"猫追狗"和"狗追猫"在它眼里完全一样。所以位置信息必须外部注入：

| 类型 | 做法 | 代表 |
|---|---|---|
| **绝对位置编码** | 每个位置加一个固定/可学习向量 | 原始 Transformer（正弦）、ViT（可学习） |
| **相对位置编码** | 注意力分数里加"相对距离"偏置 | Swin、T5 |
| **旋转位置编码 RoPE** | 位置编码成**旋转**作用在 Q、K 上 | **LLaMA / 现在的主流 LLM** |

**RoPE 现在是事实标准**——天然编码相对位置，长度外推能力更好。

> 对比：**卷积天生有位置感**（A6 的局部性），所以 CNN 不需要位置编码。**这是注意力和卷积最根本的差别之一。**

## 4. 多头：是"视角"不是"容量" ⭐ 常见误解

实测（`d_model=512`）：

```
 1 个头 (每头维度 512) : 参数量 1048576
 4 个头 (每头维度 128) : 参数量 1048576
 8 个头 (每头维度  64) : 参数量 1048576
16 个头 (每头维度  32) : 参数量 1048576
```

**参数量完全相同。**

> 📌 **常见误解**：以为多头 = 多个完整注意力并联 = 容量变大。
> **实际上 `d_model` 被切分给各头**（512 = 8×64），不是每头都用满 512。

**多头的价值在于多个独立的"关注视角"**：

- 单头：softmax 只能形成**一个**注意力分布，每个位置只能聚焦一种关系
- 多头：8 个独立分布，可同时关注语法依赖、指代、局部邻域、长程关联……

**代价**：每头维度变小（64），单个关系的表达精度下降。所以头数不是越多越好——**是"关系多样性"与"单关系精度"的权衡**。

## 5. O(n²) 复杂度

实测（d=64，batch=8）：

```
序列长度 n | 注意力矩阵    | 耗时(ms) | 相对 n=128
128       | 128×128     | 0.32    | 1.0 ×
256       | 256×256     | 1.99    | 6.3 ×
512       | 512×512     | 4.80    | 15.1 ×
1024      | 1024×1024   | 11.32   | 35.6 ×
2048      | 2048×2048   | 38.81   | 122.0 ×
```

**序列翻倍代价约 4 倍**（实测略高于理论，还有内存带宽影响）。

瓶颈是那个 **n×n 矩阵**——既是计算量也是显存。对应的优化：

- **FlashAttention**：不 materialize n×n 矩阵，分块计算 + 重计算，**显存 O(n²)→O(n)**（计算量不变，但省了大量显存读写所以更快）
- **线性注意力 / Performer / Linformer**：核技巧或低秩近似，降到 O(n)
- **稀疏 / 滑窗注意力**：只算局部或部分位置（Longformer、BigBird）

> 对比：**卷积是 O(n)**。**注意力用 O(n²) 换来"任意两点一步直达"**——这是它的核心权衡。

## 6. ViT：图像怎么变成序列

实测形状流动：

```
输入图像              : (2, 3, 224, 224)
Conv2d(k=16, s=16)   : (2, 768, 14, 14)   ← 14×14 = 196 个 patch
展平成序列            : (2, 196, 768)
拼上 CLS token        : (2, 197, 768)     ← 197 = 1 + 196
+ 位置编码 → Transformer Encoder → 取 CLS 那一行当全局特征
```

**① patch embedding 本质是 `kernel=stride=16` 的卷积。** 所以 **ViT 第一层其实还是卷积**，之后才是纯注意力。

**② CLS token**：可学习的"占位符" token，不对应任何图像内容，通过注意力**聚合全部 patch 信息**，最后拿它当全局表示。

> 💡 这和本项目的 GAP 是**两种全局聚合方式**：GAP 是**无参数平均**，CLS token 是**可学习的加权聚合**（权重由注意力算出）。

## 7. 注意力 vs 卷积：归纳偏置的取舍 ⭐

| | **卷积**（A6） | **注意力** |
|---|---|---|
| 感受野 | **局部**，靠堆深度扩大（ResNet18 要 18 层才到 435） | **全局**，**一层任意两点直达** |
| 位置信息 | **天生具备**（局部性 + 平移不变） | **完全没有**，必须外部注入 |
| 归纳偏置 | **强**（局部性 + 平移不变 + 参数共享） | **弱**，几乎什么都不假设 |
| 复杂度 | **O(n)** | **O(n²)** |
| 数据需求 | 小数据也能训 | **需要大量数据**才能超过 CNN |

> **核心权衡**：
> **偏置强 = 假设多 = 小数据高效，但上限受假设约束。**
> **偏置弱 = 假设少 = 需更多数据"从头学出"规律，但上限更高。**

这解释了著名现象：**ViT 在 ImageNet-1k（130 万张）上训不过 ResNet，但在 JFT-300M（3 亿张）上大幅超越。**

**折中**：Swin Transformer 把注意力限制在局部窗口（重新引入局部性偏置）+ 滑窗实现跨窗口连接。

## 8. 回到本项目：VPR 里的 Transformer

补全 M2 §6.2 技术谱系表的后半段。

### 8.1 MixVPR (WACV'23)

用 **MLP-Mixer** 而非注意力做聚合：对 CNN 输出的特征图，交替做"跨空间位置混合"和"跨通道混合"，全是 MLP。

**优势**：**没有 O(n²)**；特征图 token 数固定（如 14×14=196），不需要处理变长序列。

### 8.2 SALAD (CVPR'24)

把"局部特征分配到聚类中心"（NetVLAD 做的事）建模成**最优传输问题**，用 Sinkhorn 求解。

**和注意力的关系**：Sinkhorn 本质是**双向归一化的 softmax**（行列都归一化），相当于带约束的注意力——保证"每个特征被分配的总量"和"每个中心接收的总量"守恒，避免所有特征挤向同一中心。

### 8.3 AnyLoc / DINOv2 ⭐ 与本项目最相关

**DINOv2 是自监督训练的 ViT**（用的正是 B3 那套对比学习思路）。

**AnyLoc 的发现**：直接拿 DINOv2 中间层特征 + VLAD 聚合，**零训练**，在跨域场景（昼夜、季节）大幅超过专门训练的 VPR 模型。

> 📌 **对本项目的直接意义**：
>
> 核心痛点是**昼夜域差异**，而当前解法是"在小数据上微调 ResNet18"——M7 量化出这条路会过拟合（泛化间隙 34.8 点）。
>
> **AnyLoc 是另一条思路：不微调，换一个泛化能力本来就强得多的 foundation model 特征。** 自监督在海量数据上训出的特征，对光照这类变化天然更鲁棒。
>
> **这是"为什么不用更好的方法"的最佳回答之一**：不是泛泛说"可以换更强的 backbone"，而是"**我的问题是跨域泛化，而 DINOv2 这类自监督 foundation model 恰好在跨域上最强且零训练——对我这种只有 70 个训练样本的场景比微调更对症**"。

## 9. 高频追问

### Q：为什么 Transformer 用 LayerNorm 不用 BatchNorm？

> A7 §4.1：**只有 BN 依赖 batch**。NLP 里序列长度不一、batch 内统计量不稳定，推理时 batch 还可能是 1。LayerNorm 对**每个样本单独归一化**，与 batch 无关。

### Q：Pre-LN 和 Post-LN 的区别？

> - **Post-LN**（原始论文）：`LN(x + Sublayer(x))`。深层训练不稳，**需要 warmup**
> - **Pre-LN**（现在主流）：`x + Sublayer(LN(x))`。**残差路径上完全没有 LN**，梯度无阻碍直通（A8 的梯度高速公路），**训练稳定、可不用 warmup**

### Q：FFN 那一层干什么？

> 注意力只做"信息在位置之间的混合"，本质是**线性加权**。FFN（两层 MLP，中间放大 4 倍）提供**非线性变换**和特征的深度加工。有观点认为 FFN 才是模型存储知识的地方（key-value memory 解释）。

### Q：Encoder-only / Decoder-only / Encoder-Decoder？

> - **Encoder-only**（BERT、ViT）：双向注意力，适合理解任务
> - **Decoder-only**（GPT）：**因果掩码**只能看左边，适合生成，**现在 LLM 主流**
> - **Encoder-Decoder**（T5、原始 Transformer）：序列到序列，如翻译

### Q ⭐：注意力和卷积你会怎么选？

> 取决于数据量和任务。卷积的归纳偏置强——局部性、平移不变、参数共享，等于免费给了模型正确的假设，所以小数据下更高效；但上限受这些假设约束。注意力几乎不做假设，需要大量数据才能自己学出这些规律，但上限更高。
>
> 最直接的证据是 ViT 在 ImageNet-1k 上打不过 ResNet，换到 JFT-300M 就大幅超越。折中方案像 Swin 把注意力限制在局部窗口，等于重新引入局部性偏置。
>
> 具体到我这个项目，训练数据只有 70 个样本，纯 ViT 从头训完全不现实；但如果用 DINOv2 那种在海量数据上自监督预训练好的 ViT 特征，**不训练直接用**，反而是最对症的——因为我的痛点是跨域泛化，而那正是 foundation model 最强的地方。

## 10. 小结

| 要点 | 内容 |
|---|---|
| **注意力的本质** | **可微的软检索**：topk 换成 softmax 加权，因为 topk 不可导 |
| **为什么除 √d_k** ⭐ | `QKᵀ` 是 d 项之和，**std ∝ √d**（实测与 √d 完全吻合）。不缩放时**熵从 2.12 崩到 0.08** |
| **排列等变** ⭐ | 实测打乱输入输出只跟着打乱。**自注意力看不到顺序**，位置编码必需。RoPE 是事实标准 |
| **多头** ⭐ | **参数量与单头完全相同**。`d_model` 被切分。多的是**视角**不是容量 |
| **复杂度** | **O(n²)**，n 从 128→2048 耗时涨 122 倍。FlashAttention 把显存降到 O(n) |
| **ViT** | patch embedding **本质是 kernel=stride=16 的卷积**；CLS token 是**可学习的全局聚合** |
| **vs 卷积** ⭐ | 卷积偏置强、小数据高效；注意力偏置弱、需大数据但上限高 |
| **对本项目** | **AnyLoc/DINOv2 最对症**——痛点是跨域泛化，自监督 foundation model 在跨域上最强且零训练 |
