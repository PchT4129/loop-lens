# 附录 H · 残差连接与梯度消失/爆炸

> 第一梯队 ③。本项目用的就是 ResNet，而 ResNet 的全部创新就是一个加号。
> 本章也解释了 M2 里"为什么 `nn.Sequential(*children())` 这个写法能成立"。

---

## 1. 先看那个反常现象：退化问题

2015 年前的共识是"网络越深越强"。但何恺明团队发现：

> **把 20 层网络加深到 56 层，不但测试误差更高，连训练误差都更高。**

**"训练误差也更高"排除了过拟合**（过拟合是训练好、测试差），这里是**连训练集都拟合不了**。

这更说不通——理论上 56 层完全可以模仿 20 层：只要让多出来的 36 层学成**恒等映射** `f(x)=x`，性能就该和 20 层一样。

**它连"什么都不做"都学不会。** 这个现象叫**退化问题（degradation）**。

---

## 2. 梯度消失的机制：连乘

反向传播是**链式法则**，梯度每经过一层就乘上一个系数。**连乘的威力**（实测）：

```
每层乘 0.90 → 传过 50 层后剩  0.0052 倍     ← 消失
每层乘 0.99 → 传过 50 层后剩  0.605  倍
每层乘 1.00 → 传过 50 层后剩  1      倍
每层乘 1.01 → 传过 50 层后剩  1.64   倍
每层乘 1.10 → 传过 50 层后剩  117    倍     ← 爆炸
```

> 📌 **关键洞察：只要每层系数偏离 1，深度一深就指数级偏离。**
> 0.9 和 1.1 看起来都离 1 不远，50 次方后一个 0.005 一个 117。

- **梯度消失**：浅层梯度≈0 → 浅层几乎不更新 → **前面的层等于没在训练**
- **梯度爆炸**：梯度变天文数字 → 参数跳到无穷远 → loss 变 NaN

---

## 3. 激活函数的角色

那个"每层的系数"，来源之一是**激活函数的导数**（实测）：

```
Sigmoid  导数最大值 = 0.2500
Tanh     导数最大值 = 1.0000
ReLU     导数最大值 = 1.0000
```

**sigmoid 导数最大只有 0.25**，且只在 x=0 处取到，两侧迅速趋近 0。

```
0.25^50 ≈ 1e-30
```

**用 sigmoid 堆深层网络，梯度必然消失**，这是数学上注定的。

**ReLU 正区间导数恒为 1**——乘 1 不改变量级。**这才是 ReLU 取代 sigmoid 的核心原因**，不是因为它"更像神经元"，而是**它不衰减梯度**。

（代价是负区间导数为 0，可能"神经元死亡"，于是有 LeakyReLU、GELU 等变体。）

---

## 4. 核心实验：梯度沿层的真实分布 ⭐

两个 **30 层**网络，**唯一区别**是每个块的 forward：

```python
class PlainBlock(nn.Module):
    def forward(self, x):
        return self.f(x)          # 普通

class ResBlock(nn.Module):
    def forward(self, x):
        return self.f(x) + x      # 残差，只多了 "+ x"
```

反向传播一次，测各层梯度范数：

```
层     | 普通网络梯度      | 残差网络梯度      | 残差/普通
-------|-----------------|-----------------|------------
第1    | 2.093e-08       | 1.391e+01       | 6.6 亿倍
第5    | 2.560e-08       | 1.391e+01       | 5.4 亿倍
第10   | 2.642e-07       | 1.373e+01       | 5194 万倍
第15   | 6.961e-06       | 1.210e+01       | 174 万倍
第20   | 1.702e-04       | 1.136e+01       | 6.7 万倍
第25   | 2.792e-03       | 1.019e+01       | 3649 倍
第30   | 6.119e-02       | 8.744e+00       | 143 倍
```

**从下往上读（梯度传播的方向）：**

- **普通网络**：从第 30 层 `6.1e-02` 衰减到第 1 层 `2.1e-08`，**衰减 300 万倍**。第 1 层梯度是 `0.00000002`——**这层根本没在训练**
- **残差网络**：从 `8.7` 到 `13.9`，**各层在同一量级**

```
最深层/最浅层 梯度比值：
  普通网络: 3.42e-07   ← 浅层梯度被压到几乎为 0
  残差网络: 1.59       ← 各层量级接近
```

> 📌 **这张表就是"退化问题"的直接答案**：56 层训练不好不是表达能力不够，而是**前面几十层收不到有效梯度，根本没在学**。

---

## 5. 残差连接：就一个加号

```
y = F(x) + x
```

`F(x)` 是原本那些层（conv→BN→ReLU→conv→BN），`+x` 把输入**直接加到输出上**。这条绕过 `F` 的通路叫 **skip connection / shortcut**。

**整个 ResNet 的核心创新只有这一个加号。**

---

## 6. 为什么有效：三个层次

### 6.1 解释一：梯度高速公路（最直接）

```
∂y/∂x = ∂F/∂x + 1
                 ↑ 关键就是这个 +1
```

实测（设 `F(x) = 0.5x`）：

```
普通 y = F(x)      ->  dy/dx = 0.5
残差 y = F(x) + x  ->  dy/dx = 1.5
```

反向传播时梯度沿两条路走：一条穿过 `F`（可能被衰减），一条走 shortcut（**完全不衰减**），两者相加。

> **"梯度高速公路"的含义：即使所有 `F` 都把梯度掐灭了，shortcut 这条路依然畅通。**

⚠️ **一个必要的纠正**：上面 `1.5^30 = 1.9e5` 看起来像要爆炸。真实情况是网络会把 `F` 学得比较小（`∂F/∂x ≈ 0`），于是每层系数**接近 1 而非 1.5**，连乘后保持稳定；加上 BN 控制数值范围，整体是收敛的。

**准确说法：`+1` 给梯度设了一个"地板"，保证它不被指数级掐灭**，而不是"让它指数级放大"。

### 6.2 解释二：学"残差"比学"原映射"容易 ⭐（名字的由来）

设某层理想映射是 `H(x)`。

- **普通网络**：让这些层直接拟合 `H(x)`
- **残差网络**：让它们拟合 `F(x) = H(x) − x`，也就是**残差**

**为什么后者容易？** 回到退化问题——如果最优解就是"什么都别做"（`H(x) = x`）：

- 普通网络要让一堆非线性层**精确学出恒等映射**——非常难
- 残差网络只要 `F(x) → 0`——**把权重压到 0 就行，太容易了**

> 📌 **残差结构把"恒等映射"变成了默认值。**
>
> 网络的起点不再是"随机变换"，而是"什么都不做"，然后在此基础上学需要的偏移量。这样"加深至少不会变差"这个直觉才真正成立。

**这就是 ResNet（Residual Network）名字的来源。**

### 6.3 解释三：集成学习视角（加分点）

Veit et al., NeurIPS 2016：

> n 个残差块的网络，从输入到输出有 **2ⁿ 条路径**（每块可走 `F` 也可走 shortcut）。
> 所以 **ResNet 表现得像大量浅层网络的集成（ensemble）**。

他们还发现：**随机删掉 ResNet 中间某些块，性能只是平滑下降**——对普通网络这么干会直接崩溃。支持"多路径冗余"的解释。

## 7. 实现细节：维度不匹配怎么办

`y = F(x) + x` 要求两者形状一致。ResNet18 的实际处理（实测打印）：

**通道相同时（`layer1[0]`）—— identity 直连：**

```
BasicBlock(
  (conv1): Conv2d(64, 64, kernel_size=3, stride=1, padding=1, bias=False)
  (bn1):   BatchNorm2d(64)
  (relu):  ReLU(inplace=True)
  (conv2): Conv2d(64, 64, kernel_size=3, stride=1, padding=1, bias=False)
  (bn2):   BatchNorm2d(64)
)
```

**通道改变时（`layer2[0]`，64→128 且 stride=2）—— 需要投影：**

```
downsample = Sequential(
  (0): Conv2d(64, 128, kernel_size=1, stride=2, bias=False)
  (1): BatchNorm2d(128)
)
```

**用 1×1 卷积 + BN 把 identity 投影到目标形状**（1×1 只改通道不改空间，配 stride=2 同时下采样）。

两个能和前两章对上的细节：
- **所有 Conv 都 `bias=False`** —— 后面接了 BN（A7 §8.2）
- **最后的 ReLU 在相加之后** —— 即 `relu(F(x) + x)`

## 8. 残差与 BatchNorm 的关系

同一时期出现、解决同一大问题的**互补**手段：

| | BatchNorm | 残差连接 |
|---|---|---|
| 管什么 | **前向**传播时激活值的**分布** | **反向**传播时梯度的**通路** |
| 怎么做 | 每层把输出掰回标准分布 | 给梯度开一条不衰减的旁路 |
| 效果 | 损失曲面更平滑，可用大学习率 | 浅层也能收到有效梯度 |

**ResNet 两个都用**，这也是为什么 `BasicBlock` 里每个 Conv 后都跟着 BN。

> 被问"BN 和残差都是为了解决梯度消失吗"——**这个表就是好答案**：相关但角度不同，一个管前向分布，一个管反向通路。

---

## 9. 梯度爆炸：梯度裁剪

消失靠 ReLU + BN + 残差基本解决。**爆炸**主要靠：

```python
loss.backward()
torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)   # ← 加这行
optimizer.step()
```

把所有参数梯度拼成一个大向量，范数超过 `max_norm` 就**等比例缩小**。**方向不变，只限步长。**

RNN/LSTM 和 Transformer 训练里是标配（RNN 沿时间步展开本质是极深网络）。CNN 里用得少，因为 BN + 残差已经压住了。

---

## 10. 回到本项目

ResNet18 有 **8 个 BasicBlock**（layer1~layer4 各 2 个），每块一条 shortcut。两个直接相关的点：

### 10.1 M2 那个 `nn.Sequential(*children())` 为什么能成立

因为**残差连接封装在 `BasicBlock` 内部**——从外面看 `layer1`~`layer4` 就是普通串行模块，拆开重组不会破坏 skip。

**换成 DenseNet 或 U-Net 就不行**，它们的 skip 是**跨模块**的，`Sequential` 会丢掉。

### 10.2 为什么微调 25 步就能有效果

残差让梯度顺畅传到浅层，即使只更新 25 次各层都能收到有效信号。**换成没有残差的 30 层网络，25 步基本什么都学不到**——浅层梯度是 `1e-8` 量级。

## 11. 面试怎么答

### Q1：什么是梯度消失？为什么会发生？

> 反向传播是链式法则，梯度每经过一层就乘一个系数，所以是连乘。只要每层系数偏离 1，深度一深就指数级偏离——我算过，每层乘 0.9 传 50 层只剩 0.005，乘 1.1 则放大到 117 倍。消失的后果是浅层梯度接近 0、参数几乎不更新，等于那些层根本没在训练。
>
> 一个重要来源是激活函数：sigmoid 的导数最大只有 0.25，0.25 的 50 次方约等于 1e-30，必然消失。ReLU 在正区间导数恒为 1，不衰减梯度，这才是它取代 sigmoid 的核心原因。

### Q2 ⭐：残差连接为什么有效？

> 有三个层次的解释。
>
> **最直接的是梯度通路**：`y = F(x) + x` 求导得到 `∂y/∂x = ∂F/∂x + 1`，那个 +1 保证梯度总有一条不衰减的路径能传回去。我实测过 30 层网络，唯一区别就是加不加 `+x`：普通网络第 1 层梯度是 2.1e-08，残差网络是 13.9，差 6.6 亿倍；普通网络最浅层比最深层衰减了 300 万倍，残差网络各层在同一量级。
>
> **更本质的是它改变了学习目标**：让网络学残差 `F(x) = H(x) − x` 而不是直接学 `H(x)`。如果最优解是恒等映射，普通网络要让一堆非线性层精确学出 `f(x)=x` 非常难，而残差网络只要把权重压到 0 就行。**残差结构把恒等映射变成了默认值**，这样"加深至少不会变差"才真正成立——这也是 ResNet 名字的由来。
>
> 还有个集成视角：n 个残差块有 2ⁿ 条路径，表现得像浅网络的集成，随机删块性能只是平滑下降。

### Q3：BatchNorm 和残差连接是不是在解决同一个问题？

> 相关但角度不同。BN 管的是前向传播时激活值的分布，让损失曲面更平滑、能用大学习率；残差管的是反向传播时梯度的通路，让浅层也能收到有效梯度。两者互补，ResNet 两个都用，BasicBlock 里每个 Conv 后面都跟着 BN。

### Q4：identity 和 F(x) 维度不一样怎么办？

> 用 1×1 卷积加 BN 把 identity 投影到目标形状。ResNet 里叫 downsample，在通道数改变或者 stride 不为 1 的那个块上会出现。1×1 卷积只改通道不改空间，配合 stride=2 就能同时完成下采样。

### Q5：梯度爆炸怎么处理？

> 主要靠梯度裁剪 `clip_grad_norm_`，把所有参数梯度拼成一个向量，范数超过阈值就等比例缩小，方向不变只限制步长。RNN 和 Transformer 里是标配，因为 RNN 沿时间步展开本质是极深网络；CNN 里用得少，BN 加残差已经把问题压住了。
